# Guided speech example

`stop_robot.wav` contains the phrase "Stop the robot." synthesized locally using Windows System.Speech on 2026-11-04. It contains no recorded student or instructor speech. The guide computes its amplitude envelope from the bundled 16-bit PCM file using Python's standard library.

The displayed transcript is a worked expected output. No speech-recognition model runs on this page. Playback works from the bundled file on any platform and does not require the Windows speech API at runtime.
