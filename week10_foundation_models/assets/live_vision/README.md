# Workbench image

`workbench.jpg` is a resized derivative of **Workbench and tools**, Jeff Sheldon, November 18, 2014, CC0.

Source and license: https://commons.wikimedia.org/wiki/File:Workbench_and_tools_(Unsplash).jpg
Original: https://upload.wikimedia.org/wikipedia/commons/4/4b/Workbench_and_tools_%28Unsplash%29.jpg

The bundled image is 720 by 540 pixels, saved at JPEG quality 94. All Mission 2 questions use the same bytes. Inference uses the documented 512-pixel preprocessing. Each saved experiment includes the exact photograph and its hash. The authored visible-evidence description is not sent to the model.

To reproduce the bundled derivative, download the original to `runtime/workbench_original.jpg` and run `python scripts/prepare_live_scenes.py` from this lab folder.
