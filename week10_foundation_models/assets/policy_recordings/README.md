# Guided model-role example

`cup_reattempt.mp4` is an unmodified official OpenVLA recording used in Guided Activity 1 to illustrate a vision-language-action policy.

Source: [OpenVLA project](https://openvla.github.io/), Moo Jin Kim, Karl Pertsch, Siddharth Karamcheti and collaborators, *OpenVLA: An Open-Source Vision-Language-Action Model* (2024).

The source webpage credits its content under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Keep this attribution and `sources.json` when redistributing the clip. Downloaded November 3, 2026. Model code has a separate license and is not bundled.

The visible arm reattempts contact with a blue cup. The recording does not supply raw commands, checkpoint hashes, per-frame state or inference latency. It does not independently establish a stable final placement. The reviewed description and exact source URL are in `sources.json`.

All three missions use their own live local inference. This clip is a guided example, not a mission or a local policy execution.
